# frontkon2026

**Git Blame: AI** — Outreach Frontend Booth Challenge for FrontKon 2026 Prague.

An interactive CSS puzzle game where players fix hilarious, broken CSS pushed by "DevBot-3000" right before Friday deployment.

## Features
- **Level 1:** The Misplaced Modal (Center the modal with CSS Grid / Flexbox)
- **Level 2:** The Stacking Context War (Dock the action bar with `position: sticky; bottom: 0;`)
- **Level 3:** The Infinite Meeting Title (Text truncation with `overflow: hidden; text-overflow: ellipsis; white-space: nowrap;`)
- **Jira Bug Reports:** Authentic P0 Jira issue banners with Acceptance Criteria.
- **CodeMirror Integration:** In-browser CSS editor with syntax highlighting, autocomplete, and Tab completion.
- **Bilingual:** Full English & Czech support (`🇨🇿 CZ` / `🇬🇧 EN`).
- **Leaderboard:** LocalStorage high scores for booth speedruns.

## Getting Started

```bash
npm install
npm run dev
```
